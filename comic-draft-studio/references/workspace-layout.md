# 固定项目目录

```text
项目根目录/
├── HTML/
│   ├── 漫画目录.html
│   └── 本期中文标题.html
├── 图片/
│   └── 本期中文标题/
│       ├── 速写稿/01.png …
│       └── 上色图/01.png …
└── 底层文件/
    ├── Skill/comic-draft-studio/
    └── 项目资料/
        ├── 项目配置.json
        ├── 重新生成.command
        └── 资料/
            ├── 期次/issue-001.json
            ├── 主题.css
            └── 其他必要源数据.json
```

HTML只放网页，每期使用中文标题命名；不同期次标题相同则在标题文件名加中文期号等唯一标识，并同步fileName，不覆盖其他期次。漫画目录是所有期次的导航入口，不是某期漫画的重复副本。每次新增一期更新目录。不要生成issue-001.html、index.html等重复交付副本。

图片src相对图片根目录填写，例如 `本期中文标题/上色图/01.png`。两类图片各留一份原图；网页内嵌图片和下载包属于离线功能，不额外在磁盘重复生成ZIP或导出文件夹，除非用户要求。禁止通过清理唯一原图来去重。

初始化：`python3 <skill>/scripts/build.py --root <项目根目录> --init`。生成器自动创建三目录、底层配置、技能副本和重新生成入口。后续重建可以传项目根目录，也可以传底层文件/项目资料目录。已有旧结构不会被静默删除；迁移先核验引用和下载，再按用户清理授权处理旧副本。

项目配置内容：
```json
{"htmlDirectory":"../../HTML","assetDirectory":"../../图片","indexFile":"../../HTML/漫画目录.html","episodeLinksPrefix":"","compatibilityAliases":false}
```

路径相对底层文件/项目资料解析。技能本身不内置用户私人路径。需要保留的归档、制作记录或同步工作区归入底层文件；不要在HTML目录混入图片、ZIP、Markdown或JSON。公开技能包不能包含用户漫画和项目资料。
