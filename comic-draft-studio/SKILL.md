# 从粗稿到漫画脚本

## 首次调用：先给空页面，再引导

告知用户正在使用本技能。先在当前工作区新建 `漫画工作室` 文件夹；用户指定路径则采用该路径。所有路径通过脚本参数传入，不能使用原作者的私人路径。若文件夹已存在，读取项目数据后继续，不覆盖或清空任何现有内容。

用本技能目录下的脚本初始化：

```sh
python3 scripts/build.py --root <用户项目绝对路径> --init
```

命令中的脚本路径相对本技能目录，实际调用时使用其绝对路径。只需Python3标准库，无第三方库、网络服务器或外部技能原文依赖。

先展示返回的 `index.html` 文件链接。有文件预览工具时同时打开它，否则提供可点击链接。`assets/empty-library.html` 是随包提供的可直接打开的空白示例；实际项目由脚本生成相同界面。选题和期次必须为空，不能拿原作者的故事作为用户的初始内容。

随后简短说明用法：“这是你的空白漫画工作室。把你想画的大致情节发给我，一句话、一个画面或零散想法都可以；有想要的页数、画风或对白语言也可以一起说。”

如果用户本次已经提供粗稿，不重复索要；先展示初始化结果，再处理已有粗稿。已使用过的项目无需每次重新展示空白页面。

## 页数由用户决定

总页数明确时直接遵循。未指定时先基于具体粗稿推荐一个正整数页数及一句理由，用 `request_user_input_async` 提供不带 options 的输入框，问用户要多少页。没有该工具时在聊天中问同样问题。等待用户回答后再展开逐页脚本与出图；不要把建议值当成用户选择。用户明确授权你决定页数时可直接选择并说明。

每页格数、尺寸和版式按内容安排，同一期各页可以不同，不设默认格数。已有脚本局部修改沿用现有总页数，不反复询问。

## 创作流程

创作前读取 [输出标准](references/output-standard.json)、[叙事与速写](references/storyboard.md) 、[布局选择规则](references/layout-selection.md)及项目 `资料/个人规则.json`。最新用户指令优先。内容数据结构见 [数据格式](references/schema.md)。

1. 提取粗稿中必须保留的主画面、人物关系意图与氛围。补足动机、因果与转折，不擅自改成另一题材。细节可以合理补全，关键关系有歧义才询问。
2. 固定角色外形、服装、配饰和场景。不要继承原作者的角色、英国定位或成人题材。未指定画风时先采用黑白粗速写，内容风格随用户输入；实际使用反馈逐步形成用户自己的偏好。
3. 按确定的页数建立事件推进，按布局选择规则读取项目布局资料库，为每页选择适用参考并设计主视觉、动作、表情、视线和对白。内部可设计逐格内容，交付表格每页仅1行，不输出逐格分析。
4. 生成真正可见的黑白粗速写。若可用，读取并使用 imagegen 技能及图像生成工具；每页独立生成，可引用已看过的上一页或角色图维持一致。使用本环境工具实际支持的参数，不编造调用接口。没有图像生成能力时明确说明，只交付文字脚本与空的速写单元格，不能用空框、文字卡或现成示例冒充已生成速写。
5. 看实际图片核对人物动作、透视、表情、阅读顺序、气泡文字及连续性。修正明显错误后再交付；若工具受限或仍有偏差，说明具体限制。不要保证每次同等艺术质量或流量。
6. 保存生成资产至项目 `素材/`，写期次JSON，再构建HTML。速写直接进入脚本表格，可点击放大。暂不展示提示词；用户需要时再提供与已确认脚本、图片一致的整页提示词。

## 项目与HTML约定

首页3个标签：选题库、每期内容、创作资料。选题库是独立的粗稿列表（序号、选题、剧情粗稿），无详情链接、不绑定期次；用户要求保存粗稿时才入库。每期内容只显示“序号＋该期大纲”，整条悬停变色、点击进入详情。

详情页：脚本内容、图片、数据复盘。角色描述表在脚本表上方；脚本表为页码、场景描述、对白、速写稿。黑底浅字、标题适当内距、区块留白，速写列280px，可放大。图片支持用户本地上传和导出HTML，浏览器上传不是自动写回源文件；数据复盘留空。

初次新建期次用安全唯一ID，如 issue-001；修订沿用ID并先归档原JSON。不要默认添加多期。生成器会内嵌速写，HTML可独立打开；不能只改HTML而不改源JSON。

反馈区分单期修改与长期偏好。长期规则写项目 `资料/个人规则.json`，如需更改该项目标准，改项目 `资料/输出标准.json`；重建后显示在创作资料。不要把某用户的偏好写回公共技能，让其他用户继承。

## 可调用方式

- “使用 comic-draft-studio，帮我建立自己的漫画工作室。”
- “这是我的粗稿……，做成5页漫画脚本和黑白速写。”
- “修改这期第2页的动作和表情，保持总页数。”

当前用户只要求打包或维护技能时，不把上述首次引导误执行成要求当前用户提供新粗稿。

## 首稿校准（出图前必读）

生成或重画速写前读取 [首稿风格校准与交付](references/first-draft-quality.md)。先校准代表页，再以看过的参考扩展；实际检查简约程度、接触动作和版式，不能把工具成功当作风格验收。
