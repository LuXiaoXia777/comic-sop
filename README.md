# 漫画创作工作室

从一句话、一个画面或剧情粗稿，生成完整漫画脚本和黑白速写，并交付可独立打开的 HTML 工作室。

[下载技能包](downloads/comic-draft-studio.zip) · [技能说明](comic-draft-studio/SKILL.md) · [空白 HTML 模板](comic-draft-studio/assets/empty-library.html)

## 如何使用

将技能包解压后，把 `comic-draft-studio` 文件夹安装到支持本地技能的 AI 助手中，然后说：

> 使用 comic-draft-studio，帮我建立自己的漫画工作室。

助手会先展示空白 HTML，再引导你提供大致情节。一句话、一个画面或零散想法都可以。

> 这是我的粗稿：……。请帮我完善成完整脚本和黑白速写。

你可以指定总页数。没有指定时，助手会给出建议页数和理由，并等待你选择。每页格数、大小、特写与破框根据情节安排，不固定。

## 交付内容

- 选题库：独立保存剧情粗稿，不绑定期次。
- 每期内容：序号与大纲列表，点击进入详情。
- 创作资料：输出标准、工作流程与个人偏好。
- 每期详情：角色描述表、逐页场景与对白、黑白速写图；图片可放大。

不同用户的题材、受众、画风与规则保存在自己的项目中。技能包不包含原作者的故事、人物或私人图片。

## 运行要求

需要支持文件操作和技能指令的 AI 助手，以及 Python 3.9 或以上。生成真实速写需要助手提供图像生成能力；HTML 本身不会调用模型，也不是自动生成服务。没有图像能力时，助手需明确说明，只交付文字脚本。

HTML 构建仅使用 Python 标准库，无需安装第三方 Python 包：

```sh
python3 comic-draft-studio/scripts/build.py --root ./我的漫画工作室 --init
```

打开生成的 `我的漫画工作室/HTML/漫画目录.html`。首次选题与期次为空；再次初始化保留已有数据。生成内容后去掉 `--init` 重新构建即可。HTML 模板中的引导要求在聊天中发送粗稿，不会将输入自动发送到模型。

速写会内嵌在每期 HTML 中。浏览器手动上传的图片保存在当前浏览器，可导出含图页面；不会自动回写源文件。

## 布局参考怎样参与创作

技能内置从飞书「参考漫画」整理的10类布局用法，包括人物跨格、连续动作、表情重叠、景别过渡、局部放大及窥视视角。每次创作先按本页的叙事任务选择参考，再生成并检查速写；格数与版式不固定。

- [参考目录与原始点评](comic-draft-studio/references/layout-library.json)
- [选择与验收规则](comic-draft-studio/references/layout-selection.md)
- [原始参考图片所在文档](https://my.feishu.cn/wiki/AXCgwZR94iXKfdkxyhpcw636nab)（可能需要访问权限）

HTML的「创作资料」可查看布局应用规则。项目保存自己的 `底层文件/项目资料/资料/布局参考.json`，初始化不会覆盖用户修改。飞书新内容需再次读取整理，不会自动同步。技能包包含可离线使用的文字规则及来源索引，不含第三方漫画扫描图，也不将它们标为开源素材。

## 首稿校准

生成前读取用户已确认的风格与最新反馈，先检验代表页，再用看过的参考扩展整期。逐页检查简约程度、动作接触、布局及对白一致性；工具成功不等于用户认可。具体要求见[首稿风格校准与交付](comic-draft-studio/references/first-draft-quality.md)。


## 最新版本与目录规范

[comic-draft-studio 技能说明](comic-draft-studio/SKILL.md) · [下载技能包](downloads/comic-draft-studio.zip)

从剧情粗稿生成漫画脚本、黑白速写和独立 HTML 工作室，并支持按参考图上色。当前版本使用白底深色、脚本、角色描述、自媒体内容依次排列的三个标签，上色后脚本列为页码、速写稿、上色图、场景描述、对白，隐藏标签下的重复标题。图片列默认各307.2px、高度等比例，所有列固定宽度并支持整表横向滚动。图片只以文件名排序，不在图内添加页码；上色时核对各年龄段的发色、服装及人物连续性，保留明亮白色与色彩对比。新作或整期重画先实时读取并实际查看布局参考；相邻画格单线分隔，按叙事采用真实跨格、斜切和无框主画面。

每期使用独立中文标题和中文HTML文件名，提供目标受众语言的标题、标签、正文。上色图表头右侧提供同排居中的“下载到桌面”按钮：支持时选择桌面文件夹，否则下载离线ZIP。

解压到支持本地技能的助手技能目录后，使用 `comic-draft-studio` 调用。HTML构建需要 Python 3.9+；图片生成由助手的图像能力提供。此目录独立于小程序运行代码，不包含个人故事或第三方参考扫描图。

漫画项目默认目录：顶层只保留 `HTML/`、`图片/`、`底层文件/`。HTML仅放中文标题网页和漫画目录；图片按每期标题存放速写稿与上色图；Skill与项目资料放在底层文件内。新期次自动更新漫画目录，不生成英文ID网页副本。详见 [目录规范](comic-draft-studio/references/workspace-layout.md)。
